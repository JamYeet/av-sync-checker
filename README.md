# AV Sync Checker

Detects audio–visual offset in talking-head videos using a pretrained SyncNet model.

Work in progress.

## Data

Example clips from the GRID Audio-Visual Speech Corpus (Cooke, Barker, Cunningham & Shao, 2006), licensed under CC BY 4.0. doi:[10.5281/zenodo.3625687](https://doi.org/10.5281/zenodo.3625687)
